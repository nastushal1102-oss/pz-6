## Висновок
У процесі виконання завдань я закріпила використання основних методів контейнера: push() для додавання нових даних у кінець, front() для безпечного перегляду першого елемента, pop() для його вилучення, а також size() і empty() для контролю стану черги. Крім того, я успішно застосувала чергу для фільтрації числових послідовностей за математичними умовами, символьного аналізу тексту, роботи зі структурами даних та імітаційного моделювання черги заявок у службі підтримки.
